# 🧠 InterviewIQ: AI-Powered Mock Interviewer

**InterviewIQ** is a smart web application designed to help job seekers ace their next interview. By leveraging OpenAI's language models, it generates realistic, role-specific questions and provides instant, constructive feedback on your responses.

---

## ✨ Key Features
* **Role-Specific Generation:** Tailors questions to any job title (e.g., "Software Engineer", "Marketing Manager").
* **Interactive Chat Interface:** A seamless experience built with Streamlit.
* **Instant Feedback:** Uses AI to analyze your answers and suggest better ways to phrase them.
* **Secure:** Users provide their own API keys, keeping data private and costs transparent.

---

## 🛠️ Tech Stack
* **Frontend/Backend:** [Streamlit](https://streamlit.io/)
* **AI Engine:** [OpenAI API](https://openai.com/)
* **Language:** Python 3.9+
